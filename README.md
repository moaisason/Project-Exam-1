## The Modern Muse

The Modern Muse is a blog platform built as part of Project Exam 1. The application allows users to read blog posts, share them, and for the blog owner to create, edit, and delete posts through an authenticated interface.

The project uses the Noroff Blog API and is built using HTML, CSS and vanilla JavaScript.

## Features

- View latest blog posts in a carousel
- View all posts in a grid layout
- Open individual blog posts
- Share blog posts via URL
- Register and log in
- Create new blog posts (authenticated user)
- Edit and delete existing blog posts
- Responsive design for mobile, tablet and desktop

## API

This project uses the Noroff Blog API.

API documentation:  
https://docs.noroff.dev/docs/v2/blog/posts
